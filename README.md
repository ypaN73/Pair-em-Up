# Pair 'em Up 🎮

A modern, responsive number matching game built with vanilla JavaScript. Match pairs of numbers that are identical or sum to 10 in this addictive puzzle game!

## 🎯 Features

### Game Modes
- **Classic Mode**: Balanced gameplay with strategic number placement
- **Random Mode**: Randomized grid for unpredictable challenges
- **Chaotic Mode**: Maximum randomness for expert players

### Core Gameplay
- Match identical numbers or pairs that sum to 10
- Connect numbers horizontally, vertically, or across row boundaries
- Score points: Identical (1pt), Sum to 10 (2pt), Double 5s (3pt)
- Target score: 100 points to win

### Assist Tools
- **Hints**: Show available moves (unlimited uses)
- **Revert**: Undo last move (unlimited uses)
- **Add Numbers**: Extend grid with new numbers (10 uses)
- **Shuffle**: Rearrange existing numbers (5 uses)
- **Eraser**: Remove any single number (5 uses)

### User Experience
- 🎨 Light & Dark theme support
- 🔊 Sound effects for all interactions
- 📱 Fully responsive design (380px - 1280px)
- 💾 Auto-save and resume functionality
- ⏱️ Game timer with precise tracking
- 📊 Results history with win/loss statistics
